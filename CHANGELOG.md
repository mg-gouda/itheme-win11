## Version Numbering Guide

```
v1.0.0  — Initial public release
v1.0.1  — Bug fix (e.g. a specific control rendering incorrectly)
v1.1.0  — Minor improvement (e.g. new wallpapers, cursor update, new component)
v2.0.0  — Major change (e.g. full redesign of a variant, new variant added)
```

### When to release a new version
- **Patch (1.0.X):** Visual bug fixed. A color was wrong, a bitmap was misaligned.
- **Minor (1.X.0):** New content added without breaking anything. New wallpapers,
  updated cursors, a new sound scheme, one component redesigned.
- **Major (X.0.0):** A variant's visual identity changes significantly. A fourth
  variant is added. Breaking change to the install process.
